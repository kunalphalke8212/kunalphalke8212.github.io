I'm a DevOps and cloud engineer with an M.Sc. in Computer Science and 1.5 years of hands-on experience provisioning, deploying and running production infrastructure on Linux and AWS.

My toolkit is Linux, AWS (EC2, VPC, S3, IAM, EBS), Docker, Vagrant, Bash and Git, backed by Python and Java for scripting and automation. I'm looking for a DevOps, Cloud or Site Reliability Engineer role.
